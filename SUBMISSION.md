## Title

Aperture: GenLayer Spinner

## Notes / Description

Aperture is a production-ready GenLayer loading spinner built directly from the mark. The two outer wings close inward with exact mirrored motion while the center compresses into a brief lock state, then the geometry releases cleanly back to the untouched GenLayer mark. The self-contained SVG uses a purple, indigo, and cyan gradient (#8B5CF6, #6366F1, #06B6D4), loops smoothly in 1.34s, supports reduced motion, and remains readable from 16 to 64px on light and dark surfaces. The repository also includes reusable CSS, an optional React/TypeScript wrapper, structural validation, a design playground, and a responsive Portal-style deployment showing the same spinner in page, panel, and action loading states.
